# ApexDesign Figma Starter Kit Setup Guide

---

## 1. How to Duplicate the Starter Kit
1. Open Figma and navigate to your Cynbit team workspace (or your personal Figma drafts).
2. Create a new document titled `ApexDesign System - [Your Name]`.
3. Create the following pages:
   - `Cover`: Title, version, your name, and date.
   - `Primitives`: Color swatches, typography scale, 8pt spatial grid cards.
   - `Components`: Buttons, Inputs, Modals, Cards.
   - `Prototypes`: Interactive flows demonstrating micro-interactions.

---

## 2. Setting Up Figma Variables
To sync with `tokens/*.json`:
1. In the right sidebar, click **Local variables**.
2. Create a collection named `Primitives` (Color, Number).
3. Create a collection named `Semantic` (alias variables to Primitives).
4. Export your variables using the Token Studio plugin or sync via GitHub Actions.
